# real-estate-intelligence
Пайплайн машинного обучения для сбора данных и предсказания цен на недвижимость.
Цель данного проекта продемонстрировать свои навыки в построении ml-проекта end-to-end.
Как пример демонстрации взял типичную задачку с kaggle по предсказанию цен на жильё.
Успешным результатом буду считать развёрнутое приложение по предсказанию цен на жильё по признакам пользхователя с MAE < 100 000 рублей.
