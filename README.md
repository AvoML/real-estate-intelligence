# real-estate-intelligence
# 🏠 Предсказание цен на недвижимость (Real Estate ML Pipeline)

**Статус проекта:** В разработке.

## 📌 О проекте
Данный проект представляет собой полноценный end-to-end пайплайн машинного обучения. 
Система анализирует признаки квартиры (площадь, этаж, расположение) и выдает:
1. Точную предсказанную стоимость (регрессия).
2. Бизнес-оценку: "Дорого / Дешево / По рынку" (классификация).

**Бизнес-метрика успеха:** MAE (Средняя абсолютная ошибка) < 100 000 рублей.

## ⚙️ Стек технологий
- **Данные:** Pandas, NumPy
- **ML:** Scikit-Learn, XGBoost
- **Пайплайн и структура:** Cookiecutter Data Science
- **MVP (Веб-сервис):** FastAPI / Streamlit *(выбери нужное)*
- **Развертывание:** Docker

## 🚀 Как запустить проект локально

1. Клонируйте репозиторий:
`git clone https://github.com/твое_имя/real-estate-intelligence.git`

2. Создайте и активируйте виртуальное окружение:
`python -m venv venv`
`source venv/Scripts/activate`

3. Установите зависимости:
`pip install -r requirements.txt`

4. Запустите веб-интерфейс:
`streamlit run app/main.py`
